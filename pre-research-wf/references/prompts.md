# pre-research-wf · 子代理 prompt 模板（文档镜像）

> **权威源 = `references/prw-round.dwf.ts` 内的 ask 字符串**。本文件是人读镜像，改动以脚本为准（脚本不改此文件会漂移，P-020 意识）。

| 角色 | agent 名 | 职责一句话 | 关键条款 |
|---|---|---|---|
| 区划调研员 | `调研员·<区>` | 按配额产机制条目（≥3/学科，挂轴，带一手锚）+ 涌现提名 | 一手亲取；核不到=unverified+疑点；禁凑数；提名必填可空；落盘 entries md |
| 锚点复核员 | `锚点复核员` | 独立核实抽验锚（≤3 条） | 只判锚真伪（confirmed/notFound/unclear），不评内容 |
| 回炉调研员 | `调研员·<区>-回炉` | 只补缺口学科 | 明示缺几条；禁凑数 |
| 预注册员 | `预注册员·<轴>` | 六字段预注册件（假设/判据/沙盒面/三态口径/kill/预算） | 先锁后跑；落盘 sandbox |
| 实验员 | `实验员·<轴>` | 沙盒内最小验证，三态回执 | 零生产写；kill 即停；不可满足就 escalation |
| 深度调研员 | `深读员·<轴>` | 结构必需轴的贡献学科全文级精读 | 限收敛命中；落盘 deep md |
| 锁定件合成员 | `锁定件合成员` | 把 LockSpec 写成锁定件 md + 提名池 jsonl + 下轮席位件 json（三件） | **禁改任何数字**；临床化措辞 |
| 锁定件审计员 | `锁定件审计员` | 机械核对 md/jsonl/json 与 LockSpec；不过→回炉一次后**同一审计员全清单重核**（机械对数无需换人防锚定） | 只核对不修改；issues 逐条 |
| 收卷合成人 | `收卷合成人` | 综述回顾+未竟事项+落地判据件草案（wrapUp 分支） | 未竟节照 LockSpec 逐条禁改数；逐条带出处 |

通用后缀（所有 ask 尾部）：「若判据不可满足或指令互相矛盾：escalation 明说，禁硬编凑数。」
