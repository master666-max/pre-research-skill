# 预调研方法论 · 模板与清单（references）

## §1 · 机制条目模板

每学科一节，节首一句同构问题陈述，节内机制表：

```markdown
### <学科名>（子域）

> 同构问题：<该学科解决过的、与本轴同构的问题，一句话>

| # | 机制名 | 同构钩子 | 机制要点（2-3 句） | 一手锚 | 引擎咬合面候选 | 失配标注（v1.5.0 强制） | 可实验性初判 |
|---|---|---|---|---|---|---|---|
| 1 | … | … | … | 作者/机构·年份·题名·出处(期刊/标准号/URL) | … | 表内短标（≤15 字断言，如「缺金标①」「多同名牵引②」） | NE-候选：… / 不易 |

失配详注（脚注区，v1.5.1 两段式——长文本禁挤单元格）：①前提=金标全集可对照；本库无金标→断裂=覆盖率只能上界估计。②前提=记录间无同名牵引；本库同名牵引普遍→断裂=闭包跨记录蔓延。

提名：无 ── 或 ── 提名：<学科/子域>｜同构钩子：<一句>｜一手锚：<出处>｜挂轴：<轴号>｜深掘：<理由一句，v1.6.0 候款——该学科近原生同构时标记，入矿脉识别门>
```

质量规则：
- 一手锚必须真实可核；检索到什么写什么，**禁止编造 DOI/URL/年份**；
  无法核实的成分标【未核】+疑点一句。假引用零容忍（判例：上轮调研实抓误引 6+错 DOI 4）。
- 同构钩子必须写"该机制解决什么同构问题"，且须写**关系结构**（在 X 约束下对 Y 负责 /
  靠 Z 支撑成立），不许只写学科名词、不许只写效果（v1.5.0：表面相似的词面匹配是
  mere-appearance 类比，Gentner 结构映射判据——映射只发借用许可，失配才决定怎么借、
  借了哪里会坏）。机制要点须含**源域支撑网一句**（该机制在原生域靠什么成立）。
- **失配标注（v1.5.0 强制）**：每条借入机制必须回答「原生域前提 vs 本域现状」
  （缺什么支撑/多什么干扰+预期断裂形态一句）；真寻不得写「未寻得失配」并降半票
  ——mere-appearance 嫌疑，不入实验菜单优先序（判据反转：任何真实结构映射必有
  失配，「完全对应」恰是词面撞车的标志；判例=FP2 假·记录级闭包 92% 越界、
  DRed 咬合面错指账本本体——均为迟到的失配发现，条目层标注可提前拦截）。
- 引擎咬合面写真实器械面（检索前先摸清对象的器械清单），不写臆测落点。
- 每学科 ≥3 条；不足如实注明，禁凑数。
- 每节末尾**提名行必填**（无提名写「无」）；合格提名入提名池（§9），机械收割，主代理无裁剪权。
- 文件尾附自检段：条目总数/锚点核验声明/【未核】清单/**失配标注覆盖声明**（几条标了几条未寻得）。

## §2 · 田野摸底单（十一字段）

| 字段 | 内容 |
|---|---|
| ① 身份与时点 | 系统名/维护方/版本或快照时点/存活态（在产·停滞·化石） |
| ② 演化单元 | 该系统里"什么在变"（一个 change 的定义） |
| ③ 变异入口 | 谁可提案、走什么通道、有无准入检疫 |
| ④ 选择闸 | 谁批+按什么判据+几级闸 |
| ⑤ 遗传件 | 谱系记录形态（链/谱树/changelog/签署） |
| ⑥ 判死通道 | deprecate/yank/delete/reclaim 等退出机制 |
| ⑦ 死亡后语义 | 墓碑/软删/硬删/可复活 |
| ⑧ 可数事件 | 公开工件实测 ≥2 项（如回滚率/弃用周期中位/yank 次数） |
| ⑨ 五轴对映钩 | 该系统对哪根轴的哪个问题给出了实证 |
| ⑩ 双源凭证 | 设计文档+工件各 ≥1 链接 |
| ⑪ 同构提名 | 提名：<学科/系统>｜钩子｜锚｜挂轴（无则写「无」，合格提名入池 §9） |

## §3 · 风险登记固定项（R1-R8）

| # | 风险 | 对冲 |
|---|---|---|
| R1 | 假引用（历史判例：误引+错 DOI 实抓） | 一手亲取+DOI/URL 复核门，不确定标【未核】 |
| R2 | 自反性（研究者住在研究对象里） | 预注册+结论过独立盲审+自免条款（结论不豁免自家器械受检） |
| R3 | 小实验碰生产 | 沙盒位+kill criteria+走闸前后变异监控必跑 |
| R4 | 螺旋失速/假收敛 | 失速自检条款+红队轮强制 |
| R5 | 面板成本 | 检索代理并行+分层配额+模板化+本地既有调研继承不重复铺 |
| R6 | 与相邻历史调研重叠 | 相邻面成果继承为本地一手源，重叠面只做增量 |
| R7 | 田野幸存者偏差 | 化石样本强制（每类 ≥1，跨类 ≥4） |
| R8 | 田野自述污染（README 谎言/营销漂移） | 双源摸底+工件计数优先于自述+单源不入证据 |

## §4 · 知识大区审计样例（十五区）

形式科学 / 自然科学 / 生命与医学 / 流行病与公共卫生 / 脑与神经科学 / 社会科学 /
人文学科 / 法律与制度 / 教育与学习科学 / 管理与质量工程 / 体育训练科学 /
安全与事故工程 / 工程与应用 / 计算与信息前沿 / （按主题增补区）。

审计纪律：**按区划逐区过，不按成果文献分布自查**——非显学区（教育/质量工程/
训练学等）最易整片漏检（判例：某轮按文献分布自查漏 12 门，按区划复审补齐）。
各区至少一门；已知偏差如实登记（如法律面偏薄），登记候下轮补强而非掩饰。

## §5 · 收敛表格式

| 同构问题 | 独立命中路数 | 路清单（文献学科/田野系统） | 证据等级 | 失配位（v1.5.0） | 状态 |
|---|---|---|---|---|---|

计票规则：≥3 路独立命中=「结构必需候选」；文献与田野同票；田野票带「已实装」
等级；继承既往调研卷的已收口命中行（标继承来源，不重复计）。
**失配位（v1.5.0）**：每路一条失配标注（自条目失配字段带出；深读校准发现的新失配
回填）；深读未覆盖的轴在锁定件如实登记「失配面未清点」，禁以「无失配登记」冒充
「无失配」。

## §6 · 预注册件格式

```
# <实验名> 预注册（演前锁定）
- 假设与判据（先锁后跑，判据可证伪）
- 沙盒接触面声明（零生产写）
- 读数口径（三态：咬合/不咬合/登记盲区 的判定式；残差形态如实登记具体读数）
- 预锁复锁声明（v1.4.0 强制：摸底数字=候选预锁值；执行日步 0 只读复算逐位对账；
  生产面活跃时用两级门——Tier-1 结构谓词可判死／Tier-2 点值漂移只登记不判死；
  预锁「则」与「表」冲突执行期不裁决，移交重预注册）
- 代价面读数（反噬检查款，v1.3.0 强制：≥1 个代价面指标；反噬命中即定态，
  效果侧读数随附不转化为咬合）
- 判定序（机械判，伤害与终止侧优先）：kill→反噬→咬合→空转/不咬合
- 判定序四行（v1.5.1 强制，回执必填——逐步执行锚）：回执含四行「kill=（逐条对照
  预锁 kill 判定）/反噬=（代价面读数是否命中）/咬合=（H 判据逐条结论）/空转=（排除
  依据）」，缺一行即回执不完整，按登记盲区处置
- kill criteria（何种读数即终止；命中不换靶重跑、结果不佳不重跑）
- 稳健性检查（候款：参数允差网格 ±20% 判定不得翻转；伪 kill 先验注入可达性甄别）
- 预算（单枚 ≤1 会话；超配候裁=v1.4.0：新必需轴超配须当轮收卷件如实登记且判据不回改）
```

## §7 · 产出物命名与登记惯例（沿承仓）

- 计划书：`调研-卷<N>-<主题>预调研计划书-<date>.md`
- 机制条目分批件：`调研-卷<N>-C1站1-机制条目-批<k><路>-<date>.md`

## §8 · 填写样例（真实样，供风格校准）

### 机制条目样例（一行）

| # | 机制名 | 同构钩子 | 机制要点 | 一手锚 | 引擎咬合面候选 | 可实验性初判 |
|---|---|---|---|---|---|---|
| 1 | 三区间记录链接决策 | 谁解决过"自动合并与人工复核的边界怎么定" | 按似然比 W 分三带：W>Tµ 自动并 / 复核带转人工 / Tλ≥W 拒绝；阈值按两类错误率定而非拍脑袋，且有"同误差预算下人工量最小"的最优性 | Fellegi & Sunter · 1969 · A Theory for Record Linkage · JASA 64(328) DOI:10.1080/01621459.1969.10501049 | 别名并簇的 merge 三带（T1 词表工程件） | NE-候选：用判卷数据实测 m/u 后标定 Tµ/Tλ |

### 收敛表样例（一行）

| 同构问题 | 独立命中路数 | 路清单 | 证据等级 | 状态 |

## §9 · 提名池台账与涌现提名细则（v1.2）

- **台账字段（append-only）**：提名轮 / 源报告 / 学科（子域）/ 同构钩子 / 一手锚 / 挂轴 /
  证据等级 / 状态（在池-观察-转正-退出）/ 处置轮次与理由。随每轮站5 锁定件出快照。
- **准入三判据**：①同构钩子一句可陈（禁只写学科名词）②≥1 一手锚（核不了标【未核】，未核计半票）
  ③挂轴明确。缺任一降为报告内线索行（留档，不占预算）。
- **计票**：合格提名计「提名路」，与文献/田野同票；同一份报告内多条提名不构成独立路；
  田野提名带「已实装」等级。累计 ≥3 路（可跨轮累计）→ 免观察直接入正式面板（走 A 通道）。
- **观察席**：站5 机械汇总 + 预注册排序键（证据等级[田野实装>文献带锚>文献未核]×提名路数×挂轴覆盖）；
  占野卡位 ≤2/3（其余 ≥1/3 自由探索，语义不变），默认 ≤6 席按主题裁剪；摘要级交付（每苗子 ≥1 条目
  +≥1 锚，转正后补足 ≥3）；**不进实验菜单**（递减配额全留收敛学科）；收敛表同票，命中行标「苗子晋升」。
- **退出**：连续一轮零新证据 → 登记「已探未收敛」，自动入收卷未竟事项节；超额落选留池不丢，下轮续排。
- **纪律**：主代理对合格提名无裁剪权（机械收割）；裁剪只发生在预注册排序占位时；每轮站5 锁定件
  附提名池快照（在池/晋升/退出数+理由），防静默丢弃。

## §10 · 矿脉档案与矿脉席（v1.6）

矿脉学科=与某轴近原生同构的学科（识别门三触发器见 SKILL §四：跨 ≥2 轴命中/全条目
「未寻得失配」/提名深掘标记）。矿脉发掘产物=矿脉档案 `mine-<轮>-<学科>.md`，五维
必填（缺一即档案不完整）：

1. **机制清单全集**：突破基础配额，矿脉席配额独立递增（3→8→15）；
2. **失败案例与化石**：该域自己承认的失败/废弃分支——最贵的失配情报，禁只挖正面；
3. **参数空间与定标依据**：机制的可调旋钮及各旋钮的标定来源；
4. **版本演进史**：机制自身在原生域怎么演化（证书组思想的镜像）；
5. **对比边界**：与次优机制的对比及该域最终选择它的理由。

席别规则：下轮面板矿脉席 `tier=矿脉`——不占 A/B 收敛供给、不占 ≥1/3 探索税、
不计收敛路（≥3 独立路门不动）；与 A 供给并存时席别并存票权不叠加（下游并席）。
矿脉席学科下轮深读保证位（站3 必深读，挖五维）。锁定件单列「矿脉面」节与收敛表
并排不混算；锁定件收卷语境如实登记「失配面未清点」的矿脉。
