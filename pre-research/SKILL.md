# 预调研 · 螺旋四站法（pre-research）

把一个研究主题推进为多轮收缩的跨学科预调研：广度调研 → 小实验验证 → 深度调研 →
小实验验证 → 拟定新的广度调研范围，循环收窄直至锁定前沿学科面或触发饱和收卷。全部产物落盘候批，
零越权执行；实验打在沙盒接触面上，零生产写。

## 使用边界（触发校准）

- **触发**：用户说「对 X 开展一轮预调研」「先广度调研一下 X 再决定」「写 X 的预调研计划书」「这个主题的第一性原理和元问题是什么」→ 用本技能。
- **触发**：用户要求跨学科找方法/工具/数据集且需收敛排序（几十学科量级）→ 用本技能。
- **不触发**：用户问「A 和 B 两个库选哪个」「查一下 X 的定义」→ 直接检索对比即可，不开螺旋（螺旋**首轮**成本 ≥60 学科面板，单点问题用它是杀鸡用牛刀；续轮/收尾轮按站5 锁定件收窄面板，不开新盘——先例：卷十ab C1 收尾轮实耗 2.5-3.5 会话）。

## 〇 · 总流程（六步）

1. **定元问题**（四候选淘汰法，§一）
2. **推第一性原理**（公理→FP→轴，§二）
3. **建首轮面板**（同构选学科，≥60，按知识区划审计，§三）
4. **跑循环**（四站一锁，§四；小实验五判据，§五；田野第六路，§六）
5. **每站收口**（锚点回验/计数快照/账本登记）
6. **终止三判据**触发即收卷（综述回顾件收尾，§七）

## 一 · 元问题：四候选淘汰法

为研究主题列 3-4 个候选元问题，逐个裁定并写明理由后留一个。判优标准：
- **时序内嵌**优先（含"下一版对这一版"式时间向量的问题强于静态二分）；
- 一问覆盖四问（来源/判据/继承/退场）的问题强于只覆盖一问的；
- 静态二分且预置贬义的淘汰（二分掩盖真正的判据问题）；
- 已被既往调研轮占用的问题淘汰（先查档，防元问题撞车）。

选定后操作化为**证书组**（如：变异证书/选择证书/遗传证书）——每次变化都应能
出具全部证书；缺任一证书对应一种退化形态。退化形态与第一性原理 FP1 对映。

## 二 · 第一性原理推导链

- **公理**（2-4 条）：来源只能是①项目/领域既有公理 ②既成工程事实。禁凭空设公理。
  每条公理注明出处。
- **FP**（3-5 条）：从公理推论而出，每条**可独立证伪**，且各带**本地器械对映**
  （该原理在当下系统里已有什么对应物/判例；没有对映物的 FP 是悬空思辨，删或降级）。
- **轴**（4-6 根）：每 FP 接一或多根轴，每轴带一句**同构问题**（"该领域解决过与
  本轴同构的问题"——这是后文选学科的唯一标准）。
- 每轴的关键断裂点如实写出（研究对象与借鉴原型分道的地方，如拉马克遗传在生物中
  被否证而在软件/文化中合法）。

## 三 · 首轮广度面板（≥60 学科）

- **选学科标准**：按"该学科解决过与本轴同构的问题"入选；**禁按学科目录铺**
  （既往判例：按目录铺被评"浮于表面"）。
- **面板规模**：首轮 ≥60 学科；每学科交付 ≥3 机制条目（模板见
  `references/methodology.md` §1）；不足 3 条时如实注明检索面，禁凑数。
- **大区审计**：自查按**知识体系区划**逐区过（教育/神经/质量工程/体育训练/
  流行病学/安全工程等"非显学区"最易整片漏检——判例：按成果文献分布自查漏了 12 门），
  ≥12-15 区各区至少一门；已知偏差如实登记不掩饰。
- **选学科来源四条**：①文献轴（各轴学科表）②**田野第六路**（§六，同行实建系统，
  票与文献同筛）③本地既有调研卷继承（相邻面成果作一手本地源，不重复铺开）
  ④**上轮提名池**（涌现提名转正/递补，C2 起生效，§四）。

## 四 · 四站一锁循环

```
C-k 轮：站1 广度调研 → 站2 小实验验证 → 站3 深度调研 → 站4 小实验验证
              ↑______________________________________________________|
                    站5 拟定新的广度调研范围（下一轮面板锁定件）
```

- **站5 是循环的显式收尾步**（PDCA 的 Act 位）：产出"下一轮面板锁定件"=
  预注册面板（收敛供给 × 实验存活供给 × 野卡 ≥20%）+ 时新棘轮推进一档；
  **零锁定不开下轮**——回边由锁定件强制，防滑回线性瀑布。
- **收窄公式**：面板(k+1) = A×B×C。A=站k 中 ≥3 路独立收敛的同构问题的学科供给方；
  B=实验存活机制族的学科供给方；C=野卡位 ≥20%（探索税，禁被收敛吃掉；填充顺序=
  上轮提名池优先 ≤2/3 + 自由探索 ≥1/3，见下「涌现提名」）。
- **涌现提名（v1.2，每轮站5 生效，非仅首轮边界）**：站1/站3 子代理报告每节末尾
  强制提名行（`提名：<学科/子域>｜同构钩子｜一手锚｜挂轴`，无提名写「无」）。
  合格提名（钩子一句可陈+≥1 锚+挂轴明确）入**提名池**（append-only 台账，跨轮
  累计）：计「提名路」入收敛表与文献/田野同票；累计 ≥3 路免观察直接入正式面板；
  1-2 路按预注册排序键占野卡位 ≤2/3 成**观察席**（摘要级 ≥1 条目+≥1 锚，不进
  实验菜单，收敛表同票），连续一轮零新证据退出并自动入未竟事项节。细则与台账
  格式见 `references/methodology.md` §9。
- **独立路计票**：文献独立来源与田野独立系统同票；田野票另带"已实装"证据等级；
  合格提名计「提名路」（同报告内不重复计路）。
- **失配标注（v1.5.0 强制）**：每条借入机制必须标注「原生域前提 vs 本域现状：缺什么
  支撑/多什么干扰+预期断裂形态一句」；寻不得写「未寻得失配」并降半票（mere-appearance
  嫌疑，不入实验菜单优先序）。判据源=Gentner 结构映射：**同构只发借用许可，失配才
  决定怎么借、借了哪里会坏**；「完全对应」恰是词面撞车信号。收敛表每路带失配位，
  深读校准回填；候选行未竟须附共性失配句（已有路的失配标注聚敛）。模板见
  `references/methodology.md` §1/§5。
- **时新棘轮**（前沿锁定）：轮1 不限年代 → 轮2 ≥2005 → 轮3 ≥2018 → 轮4 ≥2024
  （按对象领域校准锚年）。
- **深度棘轮**：摘要级（每学科 ≥3 机制、各 ≥1 一手锚）→ 全文精读（限收敛命中）
  → 方法论级（判据可复算）→ 边缘扫尾。
- **矿脉学科（v1.6.0）**：当某学科与某轴**近原生同构**（失配趋零/方法论体系完整/跨多轴
  命中）时，均一配额会漏掉对它的超深度发掘。识别门三触发器任一命中即矿脉候选：①单学科
  条目跨 ≥2 根轴命中（体系级同构）；②该学科全部条目（≥2 条）失配标注均「未寻得失配」；
  ③提名行带深掘标记（`提名：…｜深掘：理由一句`）。矿脉候选进站3 加强形态，按**固定五维
  清单**挖一遍（防漫无边际）：机制清单全集（突破基础配额，矿脉席配额独立递增 3→8→15）/
  失败案例与化石（该域自己承认的失败分支——最贵的失配情报）/参数空间与定标依据/机制自身
  版本演进史/与次优机制的对比边界。产出=**矿脉档案** `mine-<轮>-<学科>.md`。
- **矿脉不变式（v1.6.0 禁令，防单源绑架）**：矿脉档案**不计收敛路**（≥3 独立路门不动——
  单学科再深也是一个认识论传统，30 条机制可能出自同一学派）；矿脉席不占 A/B 收敛供给、
  不占 ≥1/3 探索税；矿脉席学科若同时是 A 供给，席别并存但票权不叠加（下游展开时并席）；
  挖得越深越要猎失配——五维之「失败化石」为必填节，禁只挖正面。
- **棘轮末档声明（v1.4.0）**：档位序有限封顶（第 4 档），末档后持平合法——
  续轮不造新维硬凑收紧（委托方裁决 2026-10-05 B2；判例=C4 终轮开席=收口持平无害）。
- **实验配额递减**（如 5→3→2→1）与面板收窄同构；每枚小实验独立可停。
- **轮次制**：C1 全做、C2 默认做、C3 候裁；每轮站5 锁定件过委托位点验后续轮。

## 五 · 小实验五判据与三态

五判据（全过才算小实验，否则只是演示）：
①预注册（先锁判据后跑）②沙盒接触面（零生产写）③单枚 ≤1 会话
④输出三态＝**咬合/不咬合/登记盲区**，且判定式**必含反噬检查款**（见下）
⑤kill criteria 在案。

**反噬检查款（v1.3.0 强制）**：预注册至少一个**代价面读数**（记账开销/吞吐/
误杀率/停机时长等，按对象面裁）；判定序＝**kill→反噬→咬合→空转/不咬合**
（伤害与终止侧优先，机械判）；反噬命中即定态，效果侧读数如实随附不转化为咬合
——「效果达成但代价失控」必须落反噬，不许记咬合（判例：卷十三 E1 动能账本/
E5 押金-罚没，若按旧三态语义会误记咬合）。残差形态（曲线形状不合任一预注册
形态）如实登记具体读数，禁硬塞既定态。
**kill 硬规则**：kill 命中不换靶重跑、结果不佳不重跑——终止侧结论（如「设计
变更项而非参数项」）如实登记后收枚。
**预锁复锁纪律（v1.4.0 强制；源=C3 exp-C2-AX5 登记盲区判例+review-C3/C4 总则 2）**：
预注册中引用的全部**摸底数字**（基底行数/池资格/簇数等）只是候选预锁值——执行会话
步 0 须**当日只读复算全部预锁数字**并与预锁表逐位对账；生产面活跃时（两次复锁间账本
可增长）改用**两级门**：Tier-1=结构谓词（计数/恒等式/链健全性，可判死）先过，
Tier-2=点值读数（会漂移者）**只登记不判死**。不符即按预锁分支处置（登记盲区/重预
注册），**禁现场救跑、禁把实测数字回填预锁表放宽判据**——预锁「则」与预锁「表」
冲突时执行期不裁决，移交重预注册件。
**实验配额超配候裁（v1.4.0；源=C3 expQuota 2 实耗 4 判例）**：棘轮 expQuota 是
预算口径；执行中新生 ≥3 路收敛轴需要实验而配额已尽时，允许**超配**但须 (a) 当轮
收卷件「超配候裁」如实登记 (b) 判据不据此回改——禁静默超配，也禁为守配额砍新必需
轴的实验。
**兼容声明**：复锁与两级门自 v1.4.0 起新实验强制；既有回执（v1.3.0 及以前）不回判。

**登记盲区态直接升格为下一轮候选同构问题**（问题维），与**涌现提名**（学科维，
§四）并列为循环"有机"的两条机制来源。
实验菜单从收敛表挑（收敛 ≥3 路 × 系统内有对应器械面的优先；**「未寻得失配」降半票不进优先序**）。
**注意力条款（v1.5.1）**：①回执必含判定序四行（kill/反噬/咬合/空转，缺一即不完整）；②失配标注两段式（表内短标+表下脚注详注，长文本禁挤单元格）；③子代理自报合规计数+引擎对账（selfCheck，谎报登记）。

## 六 · 田野第六路（同行实建系统）

每台在产系统=一次自然发生的演化实验。田野五条令：
1. **双源摸底**：设计文档+真实工件两源互证，单源自述不入证据；
2. **工件计数优先于自述**：实测公开工件（提交/回滚/弃用事件），不采信 README
   与营销文案；
3. **化石样本强制**：每类取样框至少 1 个已死/停维护系统（防幸存者偏差），
   跨类化石 ≥4；
4. **公开工件边界**：无访谈通道时以公开治理记录为田野，方法边界如实登记；
5. **一手链接可回验**。

取样框五类（按主题裁剪）：最近邻实建系统 / 直系同行（前沿密度最高区）/
超大 N 人类协作系统 / 账本与数据基础设施 / 制度类公开工件。
摸底单十字段见 `references/methodology.md` §2。田野随轮递进：广谱摸底→
命中机制回田深追→前沿系统转主田野。

## 七 · 失速自检与终止判据

- **失速自检**：连续两站实验零证伪**且**零新 ≥3 路收敛=螺旋未咬合 → 强制红队轮
  （对抗性检索+对抗性实验）。
- **终止三判据**：①连续两站零证伪+零新收敛=饱和；②轮次上限（3 轮，续轮候裁）；
  ③委托方叫停。
- **收卷产出**=综述回顾件（吸收了什么/放弃了什么，逐条带出处）+落地判据件草案
  （每件落点预注册）。
- **未竟事项强制披露（v1.1）**：凡未达饱和（判据①）而迫不得已收卷——轮次上限（②）
  或委托方叫停（③）——综述回顾件**必须增设「未竟事项」节**，逐条列明：未收敛的
  同构问题（带差额：还差几路独立命中）/登记盲区态实验/野卡位未探面/棘轮未走完的
  档位/**提名池存量与观察席退出件（已探未收敛）**，每条带现状一句+续轮接续建议；
  禁以「基本收敛」「大体完成」类措辞掩盖未竟面。
  饱和收卷（判据①）可免——饱和本身即循环咬合完毕的证据。

## 八 · 落地纪律（硬约束）

- **预注册先于实验**；**一手亲取**，假引用零容忍——每条机制带一手锚
  （作者·年份·题名·出处），核实到什么写什么，无法核实的成分标【未核】+疑点一句。
- **措辞卫生**：演练/实验类文档临床化措辞，禁渲染性修辞与武器化比喻。
- **账本边界**：调研文本自带锚不入账本；仅落地判据件/器械走账本标准流程
  （逐字锚定+append-only）。
- **只读他线辖区**；跨线落地走发车单不代写。
- **风险固定登记**（R1-R8 表见 `references/methodology.md` §3），随计划书落盘。
- **每站收口**：条目锚点抽验+计数快照+按仓纪律取号登记+显式 pathspec 提交。

## 九 · 产出物清单（按序）

计划书（候批，零执行）→ 机制库（文献+田野双源）+收敛表 → 小实验回执（三态）→
提名池台账（append-only，随锁定件更新）→ 新面板锁定件 →（循环）→
综述回顾件（未达饱和收卷时含**未竟事项**节）+落地判据件草案。
