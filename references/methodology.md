# 预调研方法论 · 模板与清单（references）

## §1 · 机制条目模板

每学科一节，节首一句同构问题陈述，节内机制表：

```markdown
### <学科名>（子域）

> 同构问题：<该学科解决过的、与本轴同构的问题，一句话>

| # | 机制名 | 同构钩子 | 机制要点（2-3 句） | 一手锚 | 引擎咬合面候选 | 可实验性初判 |
|---|---|---|---|---|---|---|
| 1 | … | … | … | 作者/机构·年份·题名·出处(期刊/标准号/URL) | … | NE-候选：… / 不易 |
```

质量规则：
- 一手锚必须真实可核；检索到什么写什么，**禁止编造 DOI/URL/年份**；
  无法核实的成分标【未核】+疑点一句。假引用零容忍（判例：上轮调研实抓误引 6+错 DOI 4）。
- 同构钩子必须写"该机制解决什么同构问题"，不许只写学科名词。
- 引擎咬合面写真实器械面（检索前先摸清对象的器械清单），不写臆测落点。
- 每学科 ≥3 条；不足如实注明，禁凑数。
- 文件尾附自检段：条目总数/锚点核验声明/【未核】清单。

## §2 · 田野摸底单（十字段）

| 字段 | 内容 |
|---|---|
| ① 身份与时点 | 系统名/维护方/版本或快照时点/存活态（在产·停滞·化石） |
| ② 演化单元 | 该系统里"什么在变"（一个 change 的定义） |
| ③ 变异入口 | 谁可提案、走什么通道、有无准入检疫 |
| ④ 选择闸 | 谁批+按什么判据+几级闸 |
| ⑤ 遗传件 | 谱系记录形态（链/谱树/changelog/签署） |
| ⑥ 判死通道 | deprecate/yank/delete/reclaim 等退出机制 |
| ⑦ 死亡后语义 | 墓碑/软删/硬删/可复活 |
| ⑧ 可数事件 | 公开工件实测 ≥2 项（如回滚率/弃用周期中位/yank 次数） |
| ⑨ 五轴对映钩 | 该系统对哪根轴的哪个问题给出了实证 |
| ⑩ 双源凭证 | 设计文档+工件各 ≥1 链接 |

## §3 · 风险登记固定项（R1-R8）

| # | 风险 | 对冲 |
|---|---|---|
| R1 | 假引用（历史判例：误引+错 DOI 实抓） | 一手亲取+DOI/URL 复核门，不确定标【未核】 |
| R2 | 自反性（研究者住在研究对象里） | 预注册+结论过独立盲审+自免条款（结论不豁免自家器械受检） |
| R3 | 小实验碰生产 | 沙盒位+kill criteria+走闸前后变异监控必跑 |
| R4 | 螺旋失速/假收敛 | 失速自检条款+红队轮强制 |
| R5 | 面板成本 | 检索代理并行+分层配额+模板化+本地既有调研继承不重复铺 |
| R6 | 与相邻历史调研重叠 | 相邻面成果继承为本地一手源，重叠面只做增量 |
| R7 | 田野幸存者偏差 | 化石样本强制（每类 ≥1，跨类 ≥4） |
| R8 | 田野自述污染（README 谎言/营销漂移） | 双源摸底+工件计数优先于自述+单源不入证据 |

## §4 · 知识大区审计样例（十五区）

形式科学 / 自然科学 / 生命与医学 / 流行病与公共卫生 / 脑与神经科学 / 社会科学 /
人文学科 / 法律与制度 / 教育与学习科学 / 管理与质量工程 / 体育训练科学 /
安全与事故工程 / 工程与应用 / 计算与信息前沿 / （按主题增补区）。

审计纪律：**按区划逐区过，不按成果文献分布自查**——非显学区（教育/质量工程/
训练学等）最易整片漏检（判例：某轮按文献分布自查漏 12 门，按区划复审补齐）。
各区至少一门；已知偏差如实登记（如法律面偏薄），登记候下轮补强而非掩饰。

## §5 · 收敛表格式

| 同构问题 | 独立命中路数 | 路清单（文献学科/田野系统） | 证据等级 | 状态 |
|---|---|---|---|---|

计票规则：≥3 路独立命中=「结构必需候选」；文献与田野同票；田野票带「已实装」
等级；继承既往调研卷的已收口命中行（标继承来源，不重复计）。

## §6 · 预注册件格式

```
# <实验名> 预注册（演前锁定）
- 假设与判据（先锁后跑，判据可证伪）
- 沙盒接触面声明（零生产写）
- 读数口径（三态：咬合/不咬合/登记盲区 的判定式）
- kill criteria（何种读数即终止）
- 预算（单枚 ≤1 会话）
```

## §7 · 产出物命名与登记惯例（沿承仓）

- 计划书：`调研-卷<N>-<主题>预调研计划书-<date>.md`
- 机制条目分批件：`调研-卷<N>-C1站1-机制条目-批<k><路>-<date>.md`
- 每件落盘即：写前广播 → LOG 取号（重读尾部防撞）→ 显式 pathspec 提交
- 措辞卫生：演练/实验类文档临床化，禁渲染性修辞

## §8 · 填写样例（真实样，供风格校准）

### 机制条目样例（一行）

| # | 机制名 | 同构钩子 | 机制要点 | 一手锚 | 引擎咬合面候选 | 可实验性初判 |
|---|---|---|---|---|---|---|
| 1 | 三区间记录链接决策 | 谁解决过"自动合并与人工复核的边界怎么定" | 按似然比 W 分三带：W>Tµ 自动并 / 复核带转人工 / Tλ≥W 拒绝；阈值按两类错误率定而非拍脑袋，且有"同误差预算下人工量最小"的最优性 | Fellegi & Sunter · 1969 · A Theory for Record Linkage · JASA 64(328) DOI:10.1080/01621459.1969.10501049 | 别名并簇的 merge 三带（T1 词表工程件） | NE-候选：用判卷数据实测 m/u 后标定 Tµ/Tλ |

### 反例（禁这样填）

- 同构钩子只写学科名（"统计学解决过"）→ 无效，必须写明同构的问题本身。
- 一手锚写"某博客说"或凭记忆补 DOI → 假引用零容忍；检索到什么写什么，核不到标【未核】。
