# pre-research · 预调研（螺旋四站法）

一个把**任意研究主题**推进为多轮收缩的跨学科预调研的 agent 技能（skill）：

> 广度调研 → 小实验验证 → 深度调研 → 小实验验证 → 拟定新的广度调研范围 →（循环收窄，直至锁定前沿学科面或触发饱和收卷）

适用于 ZCode / CodeBuddy 等支持 `SKILL.md` 技能目录的 agent 环境。

## 它解决什么问题

- **广度调研容易"浮于表面"**：按学科目录铺开的调研，产出的是名词堆叠。本技能用
  「同构问题」选学科——只收录"解决过与本问同构问题"的领域，首轮面板 ≥60 学科，
  并强制按**知识体系区划**（而非成果文献分布）做覆盖审计。
- **深度调研容易"深而不住"**：本技能用**收敛筛**（≥3 路独立命中=结构必需候选）和
  **小实验五判据**（预注册/沙盒接触面/单枚限时/三态输出/kill criteria）淘汰纸上机制。
- **调研容易一去不回**：循环的收尾步被显式化为「站5 面板锁定件」——零锁定不开下轮，
  回边由锁定件强制，防滑回线性瀑布。

## 循环结构

```
C-k 轮：站1 广度调研 → 站2 小实验验证 → 站3 深度调研 → 站4 小实验验证
              ↑______________________________________________________|
                    站5 拟定新的广度调研范围（下一轮面板锁定件）
```

- **收窄公式**：面板(k+1) = 收敛供给 × 实验存活供给 × 野卡 ≥20%（探索税）
- **时新棘轮**：轮1 不限年代 → 轮2 ≥2005 → 轮3 ≥2018 → 轮4 ≥2024（逐步推向前沿）
- **实验配额递减**（如 5→3→2→1）与面板收窄同构
- **田野第六路**：同行实建系统与文献同票计票，强制化石样本防幸存者偏差
- **失速自检**：连续两站零证伪且零新收敛 → 强制红队轮

## 目录结构

```
pre-research/
├── SKILL.md                  # 方法论主文件（六步流程 + 硬约束）
└── references/
    └── methodology.md        # 机制条目模板 / 田野摸底单 / 风险登记 R1-R8 /
                              # 知识大区审计样例 / 收敛表格式 / 预注册件格式 / 填写样例
```

## 快速开始

1. 把 `pre-research/` 整个目录复制到你的 agent 技能目录（如 `~/.zcode/skills/`）。
2. 触发短语：「对 X 开展一轮预调研」「写 X 的预调研计划书」「这个主题的第一性原理
   和元问题是什么」。
3. 不触发场景：单点技术选型、一次性事实检索（螺旋首轮成本 ≥60 学科面板，
   单点问题用它是杀鸡用牛刀）。

## 来源与实证

本技能的方法论从一次实际运行的预调研战役中蒸馏而来：对"引擎的演化机制"主题的
83 学科面板调研（计划书三版修订史 + 6 路并行检索 + 24 个实建系统的田野摸底 +
230+ 条带一手锚的机制条目 + 22 行结构必需候选），其修订教训（按学科目录铺=浮于
表面；按成果分布自查漏检 12 门；田野幸存者偏差；假引用零容忍）均已固化为硬规则。

## 已知限制

- 技能正文为中文；学科面板与判据模板中的术语沿用中文治理语境（账本/收卷/候批等），
  跨语言团队使用前建议先做一次术语映射。
- 假设执行 agent 具备网络检索与子代理并行能力；无检索通道时田野第六路不可用。
- 「候批/零执行」的授权模型预设了存在一个委托方（治理位）；个人独立使用时可将其
  简化为自审。
